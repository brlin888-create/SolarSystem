# Solar System Explorer  

An interactive educational website designed for the Stardance challenge to understand their positions and movements around the Sun!

This project is designed for anyone interested in astronomy who wants to learn about our planetary neighborhood. The entire website is built using HTML, CSS, and JavaScript, which makes it accessible to run and modify without installing additional software or external libraries.

# Quick Start:

If you want to try out the website, make sure you use the link: https://brlin888-create.github.io/SolarSystem/. There you can try out the project and hope you like it (nothing to download!)

# Core Features:

**Simulation**
An interactive simulation where you change pause, change speed, or open labels for the different planets in our solar system. This project is designed so that you can visually see the different speeds of the planets in our solar system which allows the learning process to be easily done. Additionally, there are information present next to the simulation so you can visually see and learn at the same time. By selecting a planet, you can learn more information about the specific planet. Not all planets available at the same time to reduce crowding in page.

**Directory**
This is where you can simply view through detailed descriptions about the different planets. This includes mercury, venus, earth, mars, jupiter, saturn, uranus, neptune. Each planet has a specific description such as if it is a terrestrial planet, gas giant, or an ice giant. Additionally, a search bar is present to learn more about each planet by searching for it in the list, and you can click on the buttons to navigate the different planets.

**Calculators**
In the section, you are able to calculate the weight of any object on these planets depending on their gravitational pull based on the mass of the object. Additionally, you are able to do a "mission log" where you log different things you write, and it will locally be saved on your computer

**Quiz**
A very short section around 10 questions where you can get quizzed about what you just learned!

**Game**
A kind of boring (lol) game where you click the rocket as many times as you can. This is kind of like cookie clicker, and the more times you click, the more points you get...
